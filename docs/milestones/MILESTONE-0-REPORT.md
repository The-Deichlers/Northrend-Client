## Focused and inherited tests

CTest runs all five inherited test executables and four startup failure checks.
`WhoaTest` now also covers capability translation, scalar render-state bounds,
texture-combine conversions, floating-state bounds, diagnostic formatting, and
parallel archive reads using a generated synthetic MPQ, and macOS clock/sleep
measurements against an independent steady clock. WhoaTest passes 107 assertions
in 10 cases on macOS. No test ships game data.

Capability cases include normal hardware, backend clamping, absent optional and
required extensions, failed observations, insufficient texture units/attributes,
invalid texture limits, and exact extension-token matching. Conversion tests
preserve the inherited six texture operations; bounds tests reject invalid blend,
cull, depth, alpha, color-write, nonfinite, and out-of-range float values.

The archive regression creates two distinct synthetic compressed files and reads
them from separate threads over 500 rounds each, checking counts and all bytes.
It exercises the shared seek/read path used by XML loading and texture workers.

Startup regressions require exit **1** for a missing `-datadir` value, nonexistent
root, unknown option, and a valid empty root with missing required data. They also
check the reported reason; no graphical failure is treated as a successful exit.

## Startup defects corrected

The inherited GLL capability initializer left texture-unit and stream counts at
zero. GLL now observes the successfully created current OpenGL context, recording
vendor, renderer, version, texture/attribute/filtering limits and required shader/
compression extensions. Missing contexts and failed queries identify their reason;
unmet requirements retain the normal fatal initialization path and exit **1**.

Observed Apple M2 identity: vendor **Apple**, renderer **Apple M2**, OpenGL
**2.1 Metal - 90.5**. Effective capabilities: **8 texture units**, **16 vertex
attributes**, **1 interleaved vertex stream**, **16384** maximum 2D texture size,
**16x anisotropy**, ARB vertex/fragment programs and S3TC. Stream capacity comes
from the actual GLL binding implementation. Unsupported cube/rectangle upload
paths are not advertised even when hardware supports those targets. All capability
fields are initialized deterministically; no alternative backend is selected.

Login-path render states now translate to existing GLDevice/OpenGL operations,
with inherited texture-combine semantics, bounds validation and coherent cached
state. Disabled legacy texture shader/coordinate-generation and clip-plane modes
are documented in code; required unsupported values fail with the state identifier.
No arbitrary counts or silent suppression of required behavior are introduced.

Windowed maximization previously entered the unfinished fullscreen path, and its
backbuffer/viewport dimensions could disagree with the drawable. Windowed startup
now retains that mode and uses physical drawable pixels for presentation. Native
zoom notifications update graphics, UI size events, and the cached input rectangle;
mouse positions stay correct after resize. Native text entry handles Unicode
characters and rejects control/function-key text. Menu titles and Command-Q match
normal macOS behavior; close events go through orderly scheduler shutdown.

Intermittent GlueXML failures were shared archive seek/read races between the
synchronous script loader and asynchronous texture workers. A direct single-thread
read succeeded, while startup reported StormLib error **1004** for changing files.
SFile archive access is now synchronized without changing data or scripts. A
separate inherited POSIX formatter used uninitialized output bytes as its format;
a checked generated-source correction selects the translated format instead.
Temporary per-frame Lua diagnostic spam is removed; actual errors remain logged.

The macOS timer previously returned tenth-milliseconds using an integer-truncated
Mach timebase ratio, making animation about ten times too fast on this M2. Sleep
also passed milliseconds to a microsecond API. Generated-source corrections now
convert ticks to real milliseconds without truncating the ratio and sleep in
milliseconds. Focused tests cover fractional timebases, large uptimes, elapsed
wall-clock time, and a 100 ms sleep. Native animations now advance at normal speed.

## Sanitizers, CI, and limits

Debug defaults to UBSan, excluding alignment for inherited binary-data layouts;
other detected UB is fatal. ASan + UBSan runs include real asset-backed startup,
input, resize, and shutdown. `ASAN_OPTIONS=detect_leaks=0` is used for manual macOS
UI runs; leak coverage is not established. Proprietary prebuilt components are
uninstrumented. This acceptance does not establish general asset-parser safety or
client/server correctness.

production packaging/distribution, and new graphics are outside this validation.

Unimplemented particle/model operations still produce startup diagnostics; the
